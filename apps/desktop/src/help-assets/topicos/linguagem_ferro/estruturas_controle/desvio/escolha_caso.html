Escolha-caso

A estrutura escolha/caso seleciona um bloco de código de acordo com a variante de um enum, Opcao<T> ou Resultado<T, E> — funcionando exatamente como match em Rust.

Diferente de linguagens antigas com queda entre casos, em Ferro cada ramo usa a seta => { ... } e termina automaticamente ao fim do bloco, sem precisar de pare. Além disso, o compilador verifica exaustividade: todas as variantes precisam ser tratadas explicitamente ou cobertas pelo curinga caso _ => { ... }.
