Limpeza de Console e Tela

No console de texto do Ferro, não existe uma instrução de limpeza destrutiva — a saída preserva o histórico da execução para facilitar testes automatizados e depuração, podendo ser separada visualmente com quebras de linha (\n) ou limpa manualmente pelo menu do painel Console.

Quando você estiver desenvolvendo aplicações gráficas com a biblioteca Graficos, use Graficos.limpar(); antes de desenhar o próximo quadro.
