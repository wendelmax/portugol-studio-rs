# Origem da ajuda

Os tópicos e diagramas vêm da tag [v2.7.5 do Portugol Studio](https://github.com/UNIVALI-LITE/Portugol-Studio/tree/v2.7.5/ide/src/main/assets/ajuda), sob a licença LGPL-3.0. Os arquivos HTML preservam o título e a seção `body`. A interface carrega os exemplos da cópia desse corpus em `tests/corpus/ajuda`.

O arquivo `bibliotecas.json` reúne as descrições, assinaturas, parâmetros e retornos das anotações de documentação do [núcleo Java da mesma tag](https://github.com/UNIVALI-LITE/Portugol-Studio/tree/v2.7.5/core/src/main/java/br/univali/portugol/nucleo/bibliotecas). Os tipos das assinaturas foram convertidos para a grafia do Portugol.
