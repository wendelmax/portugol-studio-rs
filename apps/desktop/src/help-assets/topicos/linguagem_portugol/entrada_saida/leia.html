Leia

Em alguns problemas, precisamos que o usuário digite um valor a ser armazenado. Por exemplo, se quisermos elaborar um algoritmo para calcular a média de nota dos alunos, precisaremos que o usuário informe ao algoritmo quais as suas notas. Em Ferro, a instrução de entrada de dados via teclado é chamada de "leia", pois segue a ideia de que o algoritmo está lendo dados do ambiente externo (usuário) para poder utilizá-los.

O Comando leia é utilizado quando se deseja obter informações do teclado do computador, ou seja, é um comando de entrada de dados. Esse comando aguarda um valor a ser digitado e o converte ao tipo esperado. A forma preferida é leia() como expressão: seja n: inteiro = leia(); ou n = leia();. A forma leia(variavel) continua válida por compatibilidade, sobretudo em laços com leitura repetida.

Em Ferro, leia() sem argumentos funciona como expressão: converte a linha digitada ao tipo esperado pelo contexto — inteiro, real, caracter ou logico. Para ler números, recomenda-se seja n: inteiro = leia();. Sem tipo esperado, leia() devolve uma cadeia (seja nome = leia();), pronta para ser usada em uma interpolação ou passada a uma função. O comando leia(variavel) segue válido para laços com leitura repetida.

Para utilizar leia(), atribua o valor lido a uma variável: seja nome = leia(); para texto ou seja n: inteiro = leia(); para números. Em laços de leitura repetida, leia(variavel) continua válido e aceita mais de uma variável separada por vírgula. A sintaxe está exemplificada a seguir:
