# Histórico de versões

## 0.7.0 (2026-11-28)

### Novidades

- Primeira versão pública do Ferro Studio: uma IDE educacional para aprender programação com pseudocódigo em português e avançar para Rust.
- Editor Ferro com realce, ajuda contextual, validação, formatação, execução, depuração e exemplos.
- Painel Aprender com exercícios `.licao`, progresso e explicações que conectam conceitos Ferro a Rust.
- Designer visual para criar e executar telas e projetos interativos.
- Web Playground com autocomplete da linguagem, referência de sintaxe, terminal de entrada/saída e visualização do Rust equivalente.
- Integração com projetos Cargo e edição de código Rust.
- Instaladores para Windows, Linux e macOS, incluindo pacotes Arch Linux para x86_64 e ARM64.

### Correções

- Simplifica o Rust gerado pelo Playground.
- Corrige a execução e o histórico de entrada e saída do terminal no Playground.
- Corrige os testes do runtime WebAssembly para acompanhar a interface Ferro.

- Atualiza a Ajuda, os exemplos, o README e as instruções de distribuição para Ferro Studio.
