Funções sem Retorno

Algumas funções existem para executar uma ação — como exibir mensagens com escreva ou desenhar na janela gráfica — sem devolver nenhum valor para quem as chamou.

Em Portugol-RS, não é necessário escrever nenhuma palavra reservada especial para isso: basta omitir -> Tipo na declaração da função (assim como em Rust quando se omite o retorno unitário ()). A função encerra ao chegar no fim do bloco ou ao executar retorne; sem expressão.
